# Project Collaboration

- At the start of work, read [MEMORY.md](MEMORY.md).
- Before implementing changes, discuss the approach and agree on a plan.
- Consult the agreed plan during implementation and revise it when decisions change.
- After meaningful progress or a changed decision, update [MEMORY.md](MEMORY.md).
- Keep these collaboration rules separate from task progress, which lives in [MEMORY.md](MEMORY.md).
- Record checks actually performed and what remains untested.
- Keep memory concise and replace outdated information.
- Never store secrets in `AGENTS.md` or `MEMORY.md`.
- Ask before committing or pushing.

## Project Checks

- Run `npm run check` when the environment provides `npm`.
- Do not change game code unless the task requires it.
